# SH_precipitation

The open-source code base for the paper on the linkage of Southern Hemisphere precipitation and mid-latitude blocking, submitted at npj Climate and Atmospheric Sciences. Questions, suggestions, and corrections: Miguel M. Lima (malima@ciencias.ulisboa.pt).
